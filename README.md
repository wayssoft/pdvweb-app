# pdvweb-app

Página de início do app Android **WMN PDV Web** (Wayssoft). O APK abre esta
página, que pergunta o endereço do servidor da empresa, guarda no celular e
abre o PDV Web. Só HTML/JS estático — nenhum dado de cliente fica aqui.

Fonte: `ferramentas/apk/inicio.html` do repositório privado `wayssoft/pdv-web`
(alterar lá e copiar pra cá como `index.html`).
